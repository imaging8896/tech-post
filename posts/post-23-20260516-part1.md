# GitHub Copilot 週使用上限問題詳解 (第 1 篇/共 2 篇)

## 引言

GitHub Copilot 是 GitHub 的一項全新的 AI 驅動編碼助手服務，旨在協助開發者更有效地寫出程式碼。然而，近期有開發者在使用 GitHub Copilot 時，遇到了週使用上限的問題，導致無法順利地使用此服務。在此，我們將對此問題進行深入探討，並提供可能的解決方案。

## 問題描述

在我們的 GitHub Copilot 使用過程中，當我們的月累積使用量只有 30% 時，卻收到了以下的錯誤訊息：

```
Failed to get response from the AI model; retried 5 times (total retry wait time: 91.76 seconds) (Request-ID 43C0:16D25D:329F3D1:3DKFJJB:6A084D62) Last error: CAPIError: 429 429 Sorry, you've exceeded your weekly rate limit.
```

這表示我們已經超過了週使用上限，而無法再進行任何操作。這個問題讓許多開發者感到困擾，因為在官方的[使用限制文件](https://docs.github.com/en/copilot/concepts/usage-limits#what-to-do-if-you-hit-a-limit)中，並未提供一個明確的週使用上限的 tokens 數量。
