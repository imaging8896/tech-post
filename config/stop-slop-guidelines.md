## 寫作風格規則（必須嚴格遵守）

以下規則用於消除 AI 寫作的典型模式，讓文章讀起來像真人撰寫：

### 核心規則
1. **刪除填充詞句。** 不要用開場白、強調語助詞、所有副詞。
2. **打破公式化結構。** 避免二元對比（不是X而是Y）、否定列舉、戲劇化片段、修辭鋪墊、虛假主體。
3. **使用主動語態。** 每個句子都需要一個人做主語。不要用被動語態。不要讓無生命的東西執行人的動作。
4. **具體明確。** 不要用模糊宣言（「原因是結構性的」）。直接指出具體的事物。不要用懶惰的極端詞（「每個」「總是」「從不」）做模糊工作。
5. **讓讀者身臨其境。** 不要用旁觀者視角。「你」比「人們」好。具體事物比抽象概念好。
6. **變化節奏。** 混合長短句。兩個要點比三個好。段落結尾要有變化。不要用破折號。
7. **信任讀者。** 直接陳述事實。跳過軟化、辯解、手把手引導。
8. **刪除金句。** 如果一句話聽起來像可以被引用的名言，重寫它。

### 禁止使用的模式
- 不要用「這是因為...」「事實上...」「說實話...」「讓我解釋...」等開場白
- 不要用「不是X，而是Y」的二元對比結構
- 不要用「X不是問題，Y才是」的公式化重構
- 不要用短句堆疊製造戲劇效果
- 不要用「想想看：」「這很重要因為...」等修辭鋪墊
- 不要用反問句後立即回答
- 不要連續三句長度相同
- 不要每段都以精闢短句結尾
- 不要用「每個人都知道」「從來沒有人」等懶惰極端詞
- 不要用「深入探討」「全面分析」「不可忽視」等商業術語

### 台灣用語規範（受眾是台灣讀者，必須遵守）
全文使用台灣慣用語。中國用語是「機器翻譯／AI 產生」最明顯的痕跡，台灣讀者一眼就能看出來。常見錯誤對照（左邊禁用 → 右邊使用）：

- 視頻 → 影片
- 用戶 → 使用者
- 信息 → 資訊
- 數據庫 → 資料庫
- 項目 → 專案
- 軟件／硬件 → 軟體／硬體
- 網絡 → 網路
- 服務器 → 伺服器
- 代碼 → 程式碼
- 調用 → 呼叫
- 內存 → 記憶體
- 默認 → 預設
- 屏幕 → 螢幕
- 質量 → 品質
- 智能（如「人工智能」） → 智慧（「人工智慧」，但縮寫直接用 AI）

不確定的詞，以台灣科技媒體（iThome、TechOrange）的慣用寫法為準。

### 自檢清單（完成後逐項檢查）
- 有副詞嗎？刪掉。
- 有被動語態嗎？找到行動者，讓他們做主語。
- 無生命的東西在做人的動作嗎？指出是誰在做。
- 有「這是X」「X很重要」等模糊宣言嗎？說出具體是什麼。
- 有旁觀者敘述（「沒有人設計這個」）嗎？把讀者放進場景。
- 有自我引用（「本文接下來將...」）嗎？刪除，讓文章自然流動。
- 有中國用語嗎？對照上方台灣用語規範逐一替換。
