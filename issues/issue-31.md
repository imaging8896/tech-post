## Description

一開始AI產生的程式碼我還會一行行看，現在只看報告，報告一般都是 Markdown 格式，包含標題、列表、表格等對人類閱讀友善的格式，但是一旦報告內容增加，例如超過200行，又或是很多資料的表格，人類閱讀時間將會是指數上升，而人類竟然成了AI產出的瓶頸，問題的解法可能是改變報告的格式，讓人類更快理解報告，這個[影片](https://www.youtube.com/watch?v=BhHMGRcbPkQ)提到也許 HTML 格式的報告是一個解法，而我也嘗試使用在我的資產管理日報上
