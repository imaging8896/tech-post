## Description

我一開始概念很簡單，我想建立累積性個人知識庫（knowledge base），希望它可以成為我使用 AI 時的 context，我看到了 [Obsidian](https://obsidian.md/)。

實際上能加入的東西是一點頭緒也沒有，然後我想到我的[資產管理專案](https://www.linkedin.com/posts/%E4%BF%A1%E5%AE%8F-ted-%E9%99%B3-794aa5126_ai%E5%8A%A9%E6%94%BB%E8%B3%87%E7%94%A2%E7%AE%A1%E7%90%86%E7%84%A1%E7%85%A9%E6%83%B1-%E5%AF%AB%E4%BD%9C%E6%97%A5%E6%9C%9F-2026-05-29-%E6%8A%95%E8%B3%87%E7%AE%A1%E7%90%86%E6%98%AF%E4%B8%80%E5%80%8B%E8%A4%87%E9%9B%9C%E4%B8%94%E9%9C%80%E8%A6%81%E9%95%B7%E6%99%82%E9%96%93%E5%AD%B8%E7%BF%92%E7%9A%84%E9%A0%98%E5%9F%9F-share-7466301545396072449-JLds/?utm_source=share&utm_medium=member_desktop&rcm=ACoAAB8hKCABnq3HUgI0d7G5QAO82_pGCrQEcZA)會針對單一股票或是ETF進行研究並產生研究報告，這個似乎可以放入知識庫，於是知識庫有了 research/ 資料夾。

後來又買了 Mac mini，在上面架設了14b的模型，用自身研究所的研究方法和 Opus 給予模型能做研究的能力，於是模型開始往知識庫輸入產業研究報告，漸漸地報告開始多了，哪些有用？哪些是雜訊？我這個人類已經無法一篇篇 follow。

這時 Fable 5 橫空出世，我把問題丟給他
『我要怎麼建立可以自我學習累積的知識庫？』
於是，知識庫成長成我看不懂的樣子，但我大概可以知道，概念就是『閉環』

```
這座 Obsidian vault 不只是筆記庫 — 它是一組互相咬合的回饋閉環：每一種知識資產（研究、決策、lesson、playbook）都有對應的機制驗證它、淘汰它、或把它推進成更硬的形式。本頁提供 high-level 視角，供人審視每個閉環是否仍然閉合。
```
那『閉環』是什麼意思呢？就是你的一筆知識必須要有人審核、定期審核、反論、評分他...，例如資產管理的『決策』，每次決策都會給原因，原因看起來合理，但有沒有沒想到的情況呢？實際執行後的成效呢？如何評估成效？成功或失敗後學到的教訓如何回饋？於是要有『決策閉環』
