# 有自己買 Mac mini 來架設個人小 agent 的一些訣竅

**Issue #33**
**Author:** imaging8896
**Created:** 2026-06-27T14:11:40Z

## Description

Mac mini 省空間也不想買螢幕，若是手邊有 macbook 可以使用『螢幕共享功能』，第一次設定可以拿到公司或是借一台螢幕
1. 接上螢幕開機後先連自己收機的熱點，因為要在同一個子網路才能螢幕共享，你先在手機熱點下，回家後開機第一次也使用手機熱點連上 Mac mini，再連上家中AP，這樣你的 Mac mini 和 macbook 就在同一個子網路下
2. 『系統設定』->『一般』->『共享』打開『螢幕共享』和『遠端登入』（可以SSH，要是遠端失敗你還有這條路）
3. 『系統設定』->『登入密碼』打開『重新開機後自動登入』不然開機沒有登入的話無法螢幕共享，而每次使用螢幕共享還是需要輸入密碼登入，所以安全性仍有
4. 『系統設定』->『一般』->『軟體更新』的『自動更新』設定為『僅下載』，這看個人決定，我是想手動更新作業系統和重開機，不想要AI做到一半被中斷
5. 『系統設定』->『能源』打開『避免在顯示器關閉時自動進入睡眠』
6. 使用『Tailscale』等相關軟體，給予 Mac mini public IP，這樣從外網也可以透過IP螢幕共享

應該就這些，可能還有一些沒注意到的，歡迎補充，希望大家在建立個人專屬 AI 時都能順順利利。

注意：
* 設定好後，發現很卡頓，並且常常螢幕共享會卡住，後來找到原因是 Mac mini 和 macbook 需要兩邊都把藍牙關閉，因為藍牙會讓網路不停切換，關閉後會解決
